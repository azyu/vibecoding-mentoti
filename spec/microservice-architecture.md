# 멘토-멘티 매칭 앱 마이크로서비스 아키텍처

## 아키텍처 개요

기존 모놀리틱 구조에서 마이크로서비스 아키텍처로 전환하여 확장성과 유지보수성을 향상시킵니다.

```
┌─────────────────┐    ┌─────────────────┐
│   Frontend      │    │   Backend       │
│   (Next.js)     │    │   (NestJS)      │
│                 │    │                 │
│   Port: 3000    │    │   Port: 8080    │
└─────────────────┘    └─────────────────┘
                                │
                                │ gRPC
                                │
              ┌─────────────────┼─────────────────┐
              │                 │                 │
              │                 │                 │
┌─────────────▼─────┐ ┌─────────▼─────┐ ┌─────────▼─────┐
│   User Service    │ │ Mentor Service │ │ Match Service │
│   (사용자 관리)    │ │ (멘토 관리)    │ │ (매칭 관리)   │
│                   │ │                │ │               │
│   Port: 50051     │ │   Port: 50052  │ │   Port: 50053 │
└─────────────────┬─┘ └─────────────┬─┘ └─────────────┬─┘
                  │                 │                 │
                  │                 │                 │
                  ▼                 ▼                 ▼
            ┌─────────────────────────────────────────────┐
            │              PostgreSQL                     │
            │              (Supabase)                     │
            └─────────────────────────────────────────────┘
```

## 마이크로서비스 구성

### 1. User Service (사용자 관리 서비스)
- **포트**: 50051
- **담당 기능**:
  - 회원가입/로그인
  - 사용자 정보 조회/수정
  - 인증 및 권한 관리
  - 프로필 정보 관리

### 2. Mentor Service (멘토 관리 서비스)
- **포트**: 50052
- **담당 기능**:
  - 멘토 목록 조회
  - 멘토 검색 및 필터링
  - 멘토 정렬 기능
  - 멘토 가용성 확인

### 3. Match Service (매칭 관리 서비스)
- **포트**: 50053
- **담당 기능**:
  - 매칭 요청 생성/조회
  - 매칭 요청 수락/거절
  - 매칭 요청 취소
  - 매칭 상태 관리

### 4. Profile Service (프로필 관리 서비스)
- **포트**: 50054
- **담당 기능**:
  - 프로필 이미지 업로드/조회
  - 프로필 이미지 URL 생성
  - 이미지 저장 및 관리

## 통신 방식

### Backend ↔ Microservices
- **프로토콜**: gRPC
- **직렬화**: Protocol Buffers
- **장점**: 
  - 고성능, 낮은 지연시간
  - 강타입 스키마
  - 코드 생성 지원
  - HTTP/2 기반 다중화

### Frontend ↔ Backend
- **프로토콜**: HTTP/REST
- **직렬화**: JSON
- **인증**: JWT Bearer Token

## 데이터 저장

### 데이터베이스
- **타입**: PostgreSQL (Supabase)
- **구조**: 각 마이크로서비스가 동일한 데이터베이스를 공유하되, 테이블 별로 책임 분리
- **트랜잭션**: 각 서비스 내에서 ACID 보장

### 테이블 책임 분리
- **User Service**: `users` 테이블
- **Mentor Service**: `users` 테이블 (멘토 정보 조회)
- **Match Service**: `match_requests` 테이블
- **Profile Service**: `profile_images` 테이블

## 보안 고려사항

### 서비스 간 통신
- gRPC TLS 암호화 (프로덕션)
- 서비스 간 인증 토큰
- 네트워크 레벨 접근 제어

### 데이터 보호
